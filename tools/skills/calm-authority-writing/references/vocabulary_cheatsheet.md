# Vocabulary Calibration & Banned Hype Cheatsheet (v2.0)

This cheatsheet enforces the calm-authority lexical and syntactic standards across Aaradhya's engineering ecosystem. All technical documents must strictly eliminate promotional superlatives and artificial AI writing tropes, replacing them with precise mechanical nouns, active verbs, and calibrated epistemic phrasing.

---

## 1. The Banned Hype Blacklist

The following promotional adjectives, adverbs, and marketing clichés are strictly prohibited across all surfaces:

| Prohibited Superlative | Underlying Failure Mode | Calm-Authority Engineering Replacement |
| :--- | :--- | :--- |
| *Revolutionary / Groundbreaking* | Unearned historical grandiosity. | Factual functional description (*"A diagnostic framework for..."*). |
| *Game-changing / Paradigm shift* | Clichéd exaggeration. | Quantified capability delta (*"Reduces evaluation latency by 75%"*). |
| *Seamless / Seamlessly* | Conceals friction and integration boundaries. | Explicit protocol specification (*"Connects via REST API and prediction CSVs"*). |
| *Unleash / Supercharge / Turbocharge* | Emotional marketing hyperbole. | Measurable operational action (*"Enables", "Processes", "Evaluates"*). |
| *Next-generation / Cutting-edge* | Meaningless chronological buzzword. | Specific model ID or release version (*"ESP32-S3", "v2.0"*). |
| *State-of-the-art (SOTA)* | Vague without benchmark backing. | Pinned benchmark citation (*"Achieves 98.4% validation accuracy on FairFace"*). |
| *Magic / Effortlessly* | Anti-engineering obscurity. | Deterministic operational logic (*"Executes via non-blocking async event loops"*). |
| *Ultra-fast / Lightning-fast* | Subjective speed claim. | Exact empirical metric (*"Samples IMU at 200 Hz with sub-5ms jitter"*). |
| *Eliminates all bias / 100% safe* | Unscientific impossibility. | Empirical boundary definition (*"Quantifies disparity across four demographic parity metrics"*). |
| *We are thrilled / excited to announce* | Self-indulgent emotional framing. | Factual declarative state change (*"[Feature] is now generally available"*). |

## 2. Syntactic Anti-AI Filter (Structural LLM-isms)

Beyond lexical buzzwords, calm authority requires eliminating recognizable synthetic syntax patterns:

1. **Negation-Contrast Framing ("It is not X—it is Y")**:
   - *Prohibited*: *"This is not a wrapper. It is a deterministic pipeline."* or *"Not selling. Just explaining."*
   - *Replacement*: State the affirmative mechanical truth directly: *"This deterministic pipeline executes isolated transformations on raw inputs."*
2. **Participial Tail Clauses**:
   - *Prohibited*: Tacking weak `-ing` participle clauses to the end of sentences (*"...reducing latency by 40%, ensuring high reliability and enabling scalable deployment"*).
   - *Replacement*: Split into independent clauses with direct causal consequences: *"This reduces latency by 40%. The firmware maintains timing determinism under 200 Hz load."*
3. **Nominalization Bloat**:
   - *Prohibited*: Heavy noun stacks replacing active verbs (*"conducts an evaluation of"*, *"performs quantization on"*).
   - *Replacement*: Use active transitive verbs (*"evaluates"*, *"quantizes"*).
4. **Compulsive Tricolons**:
   - *Prohibited*: Grouping every feature, benefit, or property into rigid sets of three.
   - *Replacement*: List only the strictly necessary functional properties, whether two or four.

## 3. Active Verb Transformations

Replace weak passive phrasing and promotional verbs with concrete, mechanical actions:

| Weak / Promotional Phrasing | Calm Active Verb Replacement | Example Usage |
| :--- | :--- | :--- |
| *Provides an innovative way to manage...* | **Manages / Routes** | *"The gateway routes requests to healthy worker instances."* |
| *Is designed to help users easily create...* | **Scaffolds / Generates** | *"The CLI scaffolds project boilerplates in under two seconds."* |
| *Empowers developers to unlock...* | **Enables / Exposes** | *"The SDK exposes typed interfaces for hardware timer interrupts."* |
| *Boasts unprecedented performance in...* | **Scores / Evaluates** | *"The evaluated model achieves [metric] under [documented conditions]."* |
| *Works towards minimizing...* | **Suppresses / Blocks** | *"The pipeline suppresses metric calculations for sample sizes $n < 30$."* |
| *Offers seamless compatibility with...* | **Adheres to / Ingests** | *"The parser ingests standard JSON-LD schema definitions."* |

## 4. Scientific, Benchmark & Regulatory Lexicon

When authoring formal evaluations, model cards, or compliance reports, adhere to these calibrated terminology standards:

| Calibrated Domain Term | Strict Architectural & Regulatory Invariant | Prohibited Synonym |
| :--- | :--- | :--- |
| **Harmonized** | Differing backend primitives or regulatory standards are reconciled into mathematically unified point estimates. | *Combined, merged, unified casually.* |
| **Standardized** | Follows immutable schema contracts ($n < 30$ suppression, 95% bootstrap CIs, fixed seeds). | *Normalized, generic.* |
| **Uniform** | Visual geometry, card hierarchy, and badge semantics remain identical across formats. | *Consistent, homogeneous.* |
| **Interoperable** | Operates simultaneously across web, paginated print PDF, and machine-readable JSON-LD. | *Cross-platform, portable.* |
| **Cohesive** | Narrative descriptions, empirical whiskers, and governance cards fit together without contradiction. | *Integrated, aligned.* |
| **Pareto Frontier** | Multi-objective tradeoff boundary where neither accuracy nor cost can improve without degrading the other. | *Sweet spot, best balance.* |
| **Effort Setting / Compute Budget** | Scalable computational budget allocation (e.g. `low`, `medium`, `high`, `max`). | *Thinking power, intelligence slider.* |
